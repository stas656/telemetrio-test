# telemetrio-test

A redesigned, modern SaaS landing page for [telemetr.io](https://telemetr.io), the Telegram analytics platform.

Everything lives in a single `index.html` file (no build step). Open it in any browser, or view it live on GitHub Pages.

Sections: hero with live search and dashboard preview, stats, feature bento grid, solutions tabs, how it works plus API, testimonials, pricing with monthly/yearly toggle, FAQ, CTA and footer. Supports light and dark mode and works on mobile.
